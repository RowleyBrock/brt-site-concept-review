Psychometrics specialty

Assessment Forensics & Test Security

Use response patterns, response times, and administration evidence to identify unusual results for structured investigation.

Discuss a forensic reviewReview deliverables

State assessment security problems

A program needs independent evidence about possible item exposure, unusual examinee behavior, or recurring security risks.

BRT can help define the forensic question, prepare analysis-ready data, evaluate multiple statistical indicators, and document findings for technical and program audiences.

Statistical flags are evidence for further investigation. They are not automatic determinations of misconduct. Conclusions should integrate statistical results with administration records, security procedures, and appropriate due process.

What BRT would investigate

  • Unusual item, examinee, school, form, or administration patterns
  • Response-time differences on potentially compromised items
  • Response similarity, person fit, and multivariate indicators
  • Model accuracy, false-positive risk, sensitivity, and stability
  • Patterns across administrations for recurring monitoring

Required data and methods

Match the analysis to the program and available evidence

Typical data inputs

  • Item-level responses and scores
  • Item and section response times
  • Examinee, item, form, school, and administration identifiers
  • Administration windows, incidents, seating, device, and location metadata when available
  • Item exposure and form-construction information
  • Documented data-quality and exclusion rules

Representative methods

  • Response-time and response-pattern analysis
  • Person-fit and response-similarity statistics
  • Gated lognormal response-time models
  • Machine-learning classifier evaluation
  • Compromised-item and examinee screening
  • Sensitivity, simulation, and false-positive analysis

What a state can receive

Forensic analysis plan

Questions, required fields, data checks, comparison groups, methods, thresholds, limitations, and review protocol.

Independent technical report

Reproducible results, flagged patterns, uncertainty, alternative explanations, and evidence-based recommendations for investigation.

Recurring monitoring package

Repeatable scripts or specifications, indicator dashboard requirements, review cadence, escalation rules, and trend reporting.

Research foundation

Cengiz Zopluoglu’s assessment-forensics research

Four peer-reviewed studies examine response-time models, machine learning, item preknowledge, and simultaneous identification of unusual item and examinee patterns.

  • Simultaneous detection using response-time data (2025)
  • Deterministic gated lognormal response-time model (2023)
  • Effect of item preknowledge on response time (2021)
  • XGBoost detection study (2019)
